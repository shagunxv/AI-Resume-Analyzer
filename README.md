🚀 AI Resume Analyzer

An AI-powered Resume Analyzer built using Python and NLP techniques that evaluates resumes against job descriptions and calculates an ATS (Applicant Tracking System) match score.

This project helps users identify missing skills, improve resume relevance, and optimize resumes for better internship and job opportunities.

✨ Features

✅ Upload Resume PDF  
✅ Extract Text from Resume  
✅ Skill Detection using NLP  
✅ ATS Match Score Calculation  
✅ Missing Skills Identification  
✅ Resume Analysis Visualization  
✅ Job Description Matching  

🧠 How It Works

1. User uploads a resume in PDF format  
2. The system extracts resume text using `PyPDF2`  
3. Skills are identified from the resume  
4. The resume is compared with the provided job description  
5. ATS score is generated based on skill matching  
6. Missing skills and analysis are displayed visually
